# Fieldnotes · Agent Research Studio

A Next.js research workspace backed by PostgreSQL, Prisma, Inngest, OpenAI, and Tavily. A user submits a topic; the API creates a durable job and returns its ID immediately. Inngest runs source gathering, parallel analysis and claim verification, report writing, review, optional human approval, and persistence as durable steps.

## Architecture

- **Next.js App Router** serves the dashboard, job APIs, report downloads, schedule controls, and Inngest endpoint.
- **Inngest** orchestrates five durable agents, retries transient failures, limits concurrent workflow runs, waits up to 24 hours for review approval, and checks schedules every 15 minutes.
- **OpenAI** powers each focused agent. **Tavily** supplies live search results; citations are derived from those returned URLs.
- **PostgreSQL + Prisma** persist jobs, each agent's state and output, reports, sources, and recurring tasks.
- The dashboard polls persisted state every four seconds, so leaving the page does not stop the workflow.

## Run locally

1. Install Node.js 20+ and PostgreSQL. Create an empty database named `research_studio`.
2. Copy `.env.example` to `.env` and set `DATABASE_URL`, `OPENAI_API_KEY`, `TAVILY_API_KEY`, `INNGEST_EVENT_KEY`, and `INNGEST_SIGNING_KEY`.
3. Install dependencies with `npm install`.
4. Run `npx prisma db push` to create tables.
5. In one terminal run `npm run dev`. In a second run `npx inngest-cli@latest dev -u http://localhost:3000/api/inngest`.
6. Open `http://localhost:3000`. The service connections card reports missing configuration.

For hosted deployment, point Inngest to `/api/inngest`, configure its signing/event keys, set the production database and provider keys, and deploy the Next.js app. Keep all provider keys server-side.

## Product behavior

- Jobs return `202` and a job ID without waiting for AI work. `GET /api/research` and `GET /api/research/:id` return persisted status and agent executions.
- A failed run can be retried as a new job. Human review is requested only when the automated reviewer finds material issues; approval continues with one controlled revision.
- Daily schedules store local timezone and run time. The Inngest scheduler checks due schedules every 15 minutes.
- Reports download as Markdown. The report viewer's print action supports the browser's **Save as PDF** option.

## Configuration caveats

This initial workspace is a single shared research dashboard; it does not include account login or tenant isolation. Add an authentication provider and associate API queries with `User` before exposing it to multiple customers. A real PDF file is generated by the browser print dialog rather than a server-side PDF renderer.
